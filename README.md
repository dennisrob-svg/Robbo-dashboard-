# Robbo v3

A compact personal dashboard for iPhone and iPad. The Cromer weather card now includes current conditions, wind and gusts, a rain-window summary, hourly rain probability and amount, interactive Now/Today/Tomorrow/7 Days views, and expandable coastal wave conditions. The rest of Robbo remains unchanged: Trading 212 stock links, live market prices, Libra horoscope, news, TV listings and device-local reminders.

## Publish on GitHub Pages

Upload every file in this folder to the root of the existing repository. In **Settings → Pages**, keep **Deploy from a branch**, **main**, and **/(root)** selected. Refresh the installed app once after GitHub finishes publishing so the v3 service worker takes over.
