# Robbo v2.1

A faster, compact personal dashboard for iPhone and iPad with live Cromer weather, Trading 212 stock links, live market prices, Libra horoscope, news, TV listings and device-local reminders.

## Publish on GitHub Pages

Upload every file in this folder to the root of the existing repository. In **Settings → Pages**, keep **Deploy from a branch**, **main**, and **/(root)** selected. Refresh the installed app once after GitHub finishes publishing so the v2 service worker takes over.
