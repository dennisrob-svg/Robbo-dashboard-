# Robbo Dashboard v1

This is an installable PWA (Progressive Web App) designed for iPhone.

Live cards:
- Cromer weather via Open-Meteo
- IONQ, RKLB and RGTI via TradingView
- Daily Libra horoscope via Sigastra
- UK, Business, Property and World headlines via Google News RSS + RSS2JSON

## Put it online
The simplest route is GitHub Pages:

1. Create a free GitHub account if you do not already have one.
2. Create a new repository called `robbo-dashboard`.
3. Upload all the files from this folder (not the zip itself).
4. Open Settings → Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will give you a web address for the app.

## Put it on iPhone
1. Open the GitHub Pages web address in Safari.
2. Tap the Share button.
3. Tap "Add to Home Screen".
4. Name it `Robbo` and tap Add.

The app then opens from its own Home Screen icon in a standalone app-style window.
